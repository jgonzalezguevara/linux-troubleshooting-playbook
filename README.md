# Linux Troubleshooting Playbook

Procedimientos prácticos de troubleshooting Linux, diagnóstico operativo y revisión de incidencias reales.

Este repositorio recopila comprobaciones, procedimientos y listas de verificación utilizadas habitualmente durante el análisis de problemas en servidores Linux.

Está orientado a administradores de sistemas, equipos de infraestructura, perfiles DevOps, SRE y profesionales que necesitan localizar incidencias de forma estructurada.

## Qué encontrarás

### CPU

Procedimientos para identificar procesos con alto consumo, carga del sistema, cuellos de botella y problemas de rendimiento.

### Memoria

Revisión de consumo de memoria, uso de swap, procesos problemáticos y situaciones de falta de memoria.

### Disco

Comprobaciones relacionadas con espacio ocupado, sistemas de ficheros, inodos y rendimiento de almacenamiento.

### Red

Diagnóstico básico de conectividad, DNS, rutas, puertos y servicios de red.

### Systemd

Análisis de servicios, estados, errores de arranque y problemas operativos habituales.

### Logs

Métodos prácticos para localizar errores y eventos relevantes en sistemas Linux.

### Incidencias

Checklist inicial para abordar problemas reales de forma ordenada.
